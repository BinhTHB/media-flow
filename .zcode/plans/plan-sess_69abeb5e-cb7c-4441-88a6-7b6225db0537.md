# Preset generic-text (RoyRud1902/yolo11n-text) + phân loại — bản chốt cuối

Tất cả 13 điểm review đã encode. Tradeoff v1 chấp nhận có chủ ý (ghi vào docs): subtitle lệch tâm (fansub theo speaker) → other; subtitle 1 từ lệch tâm → miss; station ID 3-5s trong video dài → other; video rất ngắn thiếu static. Phase 2: OCR content refinement + cân nhắc OR-line-like cho fansub.

## 1. Mới: `src/features/visual/text_classifier.py` (feature layer)
`TextClassifyingDetector(DetectorPort)` + `classify_generic_text_detections()`:
- fps diff-based (median Δframe/Δtimestamp, loại delta ≤0, fallback 25.0) — điểm B.
- Track tạm bằng `ClassAwareTracker` (batch); re-label bằng Detection **copy mới**, đổi CẢ class_id + class_name; non-generic pass-through.
- Thứ tự geometry-first:
  1. `subtitle` = centered (bắt buộc, cx ∈ [0.15, 0.85] & w ≤ 0.80·W) + (bottom cy ≥ 0.62·H HOẶC line-like: h ≤ 0.12·H & w/h ≥ 3)
  2. static = frame_span ≥ max(75, 0.30×span) & jitter std(cx)/W, std(cy)/H ≤ 0.01 & size jitter ≤ 0.02 → corner+nhỏ (h ≤ 0.08·H) = `watermark`, còn lại = `logo`
  3. còn lại = `other_burn_in_text`
- Hằng số module; mapping từ `CANONICAL_CLASS_NAMES` (core); `schemas.EXPECTED_CLASS_NAMES` tham chiếu core (1 nguồn sự thật).
- Conf/`_compose()`: conf lọc ở predictor (đã grep) → generic dựng adapter với conf=0.20 (khi user để 0.05 mặc định), `subtitle_rescue_conf=None`.
